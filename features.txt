List of all MiLa features

* Closures
* Implicit paramaters
* Optional paramaters
* Variadic paramaters
* Type hints
* Inplace assignment (references)
* Inplace operations
* Objects (kind of, more prototype-ish)
* Overloading
* Common string escapes (as well as hex and octal codes)
We do support unicode escapes.
* Anything as identifiers
Example: var 'Das variable Name ist ein Stück Scheiße' = 90;
* JSON parser and serializer (builtin)
* Globbing (own flavor)
* Loading native libraries
* Threads

MiLa built ins features:
* Text IO
* File IO
* Redirecting fds
* isatty
* Shelling
* System introspection
* String manipulation
* Dict, List, and Array methods
* JSON serializer and parser
* Threads
* Math opetations: pow, sqrt, tan, atan2, cos, sin, ...
* File checks (file.is_dir, file.is_file)
* Directory listing (file.list_dir)
* Error handling
* assert
* Evaluating files
* Loading native libraries
